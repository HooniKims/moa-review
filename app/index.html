사용 방법

파일을 추가하고 기준 연도를 지정한 뒤 검사를 시작하세요.

01

비교할 파일 추가

HWPX 계획서·가정통신문과 XLSX 예산표를 선택하거나 창으로 끌어다 놓으세요. 구형 HWP, XLS, PDF와 스캔 이미지는 지원하지 않습니다.

02

기준 연도 확인

기준 연도를 지정한 뒤 검사 시작을 누르세요. 명시된 날짜·인원·장소·금액 라벨과 표의 머리글을 중심으로 값을 읽습니다.

03

문서별 값과 원문 확인

항목을 선택하면 문서별 값과 문단·표·셀 위치가 나옵니다. 같은 대상의 값인지 확인하고 필요한 수정은 원본 앱에서 진행하세요.

04

검토 상태 표시와 결과 저장

확인 완료 표시는 검토 상태입니다. 원본을 수정했다는 뜻은 아니에요. 수정 후 다시 검사하고 HTML 또는 CSV로 결과를 저장하세요.

지원 범위와 주의 사항

  • 자유로운 문장, 복수 일정, 이미지 속 글자, 복잡한 병합 표의 모든 정보를 인식하지는 못합니다.
  • 불일치가 0개여도 문서 전체가 정확하다는 뜻은 아닙니다. 인식한 항목 수와 읽기 안내를 함께 확인하세요.
  • 엑셀 수식은 저장된 계산 결과를 읽습니다. 엑셀에서 최신 값으로 재계산한 뒤 저장해 주세요.
  • 확정되지 않은 기준값을 자동 선택하거나 원본 문서를 수정하지 않습니다.
  • 앱을 종료하면 문서 내용과 검토 상태는 메모리에서 사라집니다. 필요한 결과는 먼저 저장해 주세요.
