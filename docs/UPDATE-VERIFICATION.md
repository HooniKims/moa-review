# 모아검토 업데이트 검증

## 1.2.0 — 앱 디자인 개편

검증일: 2026-10-08.

- 단위 테스트 38개, UI 테스트 11개 통과. 패키징한 EXE의 문서 검사·결과 저장·설정·최소 창 화면 확인.
- 최종 ASAR의 화면 코드와 첫 화면 이미지가 소스와 일치.
- 공개 릴리즈 첨부 파일 5개의 SHA-256이 로컬 파일과 일치. 최신 릴리즈 페이지 HTTP 200 및 `latest.yml` 일치 확인.
- 실제 설치된 1.1.1에서 1.2.0을 감지하고 다운로드 완료(`available` → `ready`). 다운로드한 EXE의 SHA-512가 배포 파일과 일치.
- 검증 중 재시작 설치는 실행하지 않았다. 사용자는 필요한 검토 결과를 저장한 뒤 앱에서 설치를 선택할 수 있다.

## 1.1.1 — 설정과 제작자 표시

검증일: 2026-10-08.

- 단위 테스트 38개, UI 테스트 11개 통과.
- 패키징된 Windows EXE에서도 설정 메뉴, 제작 HooniKim 표시, 업데이트 상태 전환 확인.
- 공개 v1.1.1 릴리즈의 첨부 파일 5개 모두 로컬 SHA-256과 일치.
- `/releases/latest`는 v1.1.1로 이동하며 HTTP 200 반환. 공개 `latest.yml`도 로컬 파일과 일치.
- 실제 설치된 1.1.0에서 공개 GitHub의 1.1.1을 감지하고 다운로드 완료(`available` → `ready`). 받은 설치 파일의 SHA-512가 배포 EXE와 일치.
- 이번 검증에서는 재시작 설치를 실행하지 않았다. 실행 중인 사용자 앱의 교체는 사용자가 업데이트 설치를 선택할 때 진행된다.

단위 테스트는 상태 전환, 중복 확인 요청, 다운로드 실패 후 재시도, 누락된 릴리즈, 잘못된 버전 문자열, 일반 종료 시 자동 설치 비활성화를 검증했다. UI 진행률 테스트는 가상 이벤트로 화면 상태를 검증한다. 네트워크 통합 테스트는 실제 Electron HTTP executor와 electron-updater 다운로드·해시 검증을 사용하며 시험용 바이트 파일을 실행하지 않는다.

공개 GitHub에서 현재 버전이 최신인지 확인하는 전체 경로는 검증했다. 향후 더 높은 버전의 EXE로 실제 자동 교체하는 전체 경로는 아직 검증하지 않았다. 다운로드·해시 검증과 설치·재실행은 각각 별도로 확인한 결과다.

게시 후 실제 설치본의 업데이트 상태는 `screenshot-update-live.png`에 기록했다. `screenshot-update.png`는 준비 완료 이벤트를 주입한 UI 테스트 화면이다.

설치 이미지: image_gen.imagegen 내장 생성. `build/installer/imagegen-prompt.txt`에 최종 프롬프트 보관. 2배 크기의 BMP로 변환하여 고해상도 화면에서 선명도를 유지한다.
