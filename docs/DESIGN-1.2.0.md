# 1.2.0 화면 개편

교사가 여러 문서를 대조하는 업무 앱에 문서 작업대의 인상을 더했다. 기존의 녹색 브랜드와 프리텐다드, 문서 검토·사용 안내·설정 메뉴를 유지하면서 제목, 현재 작업 단계, 비교 값을 더 분명하게 구분했다.

## 디자인 판단

기존 화면은 연한 중성색, 비슷한 크기의 글자, 작은 강조 영역으로 구성되어 작업 영역 사이의 차이가 약했다. Taste Skill의 redesign-overhaul 방향을 적용하되, 소개 화면용 스킬의 범위에 맞춰 첫 화면을 중심으로 재구성했다. 검토 패널은 업무 도구의 밀도와 가독성을 기준으로 설계했다.

- DESIGN_VARIANCE 7: 큰 제목과 녹색 강조, 비대칭 사진 배치, 문서철처럼 구분되는 패널.
- MOTION_INTENSITY 3: 대화상자의 짧은 진입과 버튼 피드백. 운영체제의 움직임 줄이기 설정을 존중한다.
- VISUAL_DENSITY 5: 첫 화면은 여유 있게, 검토 화면은 제목을 줄여 결과 공간을 확보한다.
- 기존 Electron·CSS와 아이콘을 유지한다. 다른 디자인 시스템의 구현이라고 주장하지 않는다.
- 밝은 화면, 녹색 계열 강조, 4px 모서리를 사용한다. 오류·주의 표시는 의미에 따라 기존 색을 유지한다.

## 사용성

- 상단에 파일 추가 → 문서 검사 → 차이 확인 순서를 표시한다. 실제 파일·검사 상태와 연결하고 현재 단계에 `aria-current="step"`을 제공한다. 사용 안내에서는 숨긴다.
- 파일 추가 영역에는 설치 화면에서 이미 제작한 문서 이미지를 재사용한다. 검토 화면의 원문 배경에는 이미지를 넣지 않는다.
- 프리텐다드의 실제 400·600 굵기를 사용한다. 첫 화면 제목 56px, 검토 제목 32px, 주요 비교 값 30px, 일반 조작 버튼은 높이 44px 이상이다.
- 선택한 검토 항목에 왼쪽 선과 배경을 함께 적용한다. 문서별 값은 밑줄과 큰 글자로 강조한다.
- 작은 창에서는 제목과 연도 입력 배치를 조정하고 파일·검토 항목·근거를 각각 스크롤한다.
- 설정의 제작 HooniKim 표시, 결과 저장, 원본 열기, 업데이트 기능을 유지한다.

## 검증

2026-10-08: 단위 테스트 38개, Electron UI 테스트 11개 통과. 실제 프리텐다드 렌더링, 파일 추가·제거·재검사, 필터·검색·확인 상태, HTML·CSV 저장, 오류 복구, 업데이트 화면을 확인했다. 단계 표시 전환과 사용 안내의 단계 숨김, 1100×740 첫 화면의 가로 넘침과 파일 선택 버튼 위치를 기존 UI 테스트에 추가했다.

주요 색 조합의 대비: 기본 버튼 7.85:1, 본문 13.22:1, 사이드바 보조 글자 5.35:1, 선택 항목 글자 10.44:1. 최소 창과 1440×960 화면을 캡처해 레이아웃을 확인했다.
