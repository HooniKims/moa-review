# 원문 직접 수정

모아검토 1.3.0부터 검토 항목의 원본 근거에서 **직접 수정**을 선택할 수 있다. 사용자가 입력한 내용을 로컬에서 반영하며 AI나 외부 서버를 사용하지 않는다.

## 사용 순서

1. 문서를 검사하고 검토할 항목을 선택한다.
2. 원본 근거 옆의 **직접 수정**을 누른다.
3. 표시된 문단 또는 셀에서 필요한 부분을 고친다.
4. **수정본 저장**으로 새 파일을 저장한다.

저장 후 현재 문서 묶음의 해당 파일을 수정본으로 바꾸고 자동으로 다시 검사한다. 원본과 이미 존재하는 파일은 덮어쓰지 않는다. 원본 프로그램에서 파일을 바꿨다면 먼저 다시 검사해야 한다.

## 지원 범위

| 형식 | 직접 수정 | 원본 프로그램에서 수정 |
| --- | --- | --- |
| HWPX | 일반 문단과 표 셀의 텍스트 | 필드·개체·특수 줄바꿈이 있는 문단, 중첩 표를 포함하는 바깥 셀, 문단 추가·삭제 |
| XLSX | 텍스트·숫자·날짜 입력 셀 | 수식·배열 수식, 보호된 시트, 확장 데이터 셀, 동적 배열이 있는 통합 문서 |
| HWP | 지원하지 않음 | 한글에서 HWPX로 저장한 후 검사 |

전자서명 문서, 빈 값, 10,000자 초과 편집은 지원하지 않는다. HWPX 문단의 라벨·단위·요일도 편집창에 표시되므로 필요한 부분만 고친다. XLSX 숫자는 쉼표와 단위를 제외하고, 날짜는 `YYYY-MM-DD`로 입력한다.

## 저장 방식과 서식

- 검사 시 문단·셀의 정확한 위치와 원본 SHA-256을 기록하고 편집 및 저장 직전에 다시 확인한다.
- 기존 XML의 선택한 텍스트 영역만 수정한다. 바뀌지 않은 글자의 서식, 표 구조, 본문 이미지와 다른 ZIP 구성 요소는 유지한다. 새 글자는 해당 위치의 기존 글자 서식을 사용한다.
- HWPX는 수정한 문단의 오래된 줄 배치 정보를 제거해 한글에서 다시 배치하도록 한다. 미리보기 텍스트도 갱신한다. 참조되지 않는 오래된 미리보기 이미지는 제거하며, 참조된 미리보기 이미지가 남으면 안내한다.
- XLSX 공유 문자열은 선택한 셀에만 독립된 문자열로 저장한다. 다른 셀의 같은 문자열은 바꾸지 않는다. 텍스트로 입력한 `=`는 수식으로 실행하지 않는다.
- XLSX 수식과 셀 서식은 유지한다. 입력값이 바뀌면 기존 수식 결과 캐시를 지우고 재계산을 요청한다. 모아검토는 수식을 계산하지 않으므로 엑셀에서 열어 계산·저장한 후 최종 검사한다.
- 출력 XML을 검증하고 수정한 위치를 다시 읽어 확인한 뒤 새 파일을 생성한다. 저장은 배타적 생성으로 처리하므로 기존 파일을 덮어쓰지 않는다.

글자 수 변경은 줄바꿈과 페이지 배치에 영향을 줄 수 있다. 제출 전에는 한글이나 엑셀에서 수정본의 최종 배치를 확인한다.

## 검증 기록

2026-10-08 기준 단위 테스트 53개와 전체 UI 테스트 13개가 통과했다. 직접 수정 관련 UI 테스트는 최소 창 크기 1100×740에서도 별도로 통과했다.

직접 수정 테스트는 HWPX 문단·병합 표 셀, 여러 글자 서식, 특수 문자, 미리보기 갱신, XLSX 공유 문자열·숫자·날짜·수식 캐시, 원본 변경 감지, 저장 취소, 덮어쓰기 방지, 저장 후 자동 재검사를 다룬다. 별도 검토에서 HWPX 구조 검사와 원본·미수정 구성 요소 보존도 확인했다.

테스트용 HWPX의 참가 인원을 119명으로 바꾼 수정본을 실제 한글 2024에서 열어 오류 없이 표시되는 것을 확인했다. 모든 문서 양식의 배치를 보장하는 검증은 아니다.
